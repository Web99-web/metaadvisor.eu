# Bluesky improves photo quality and moves closer to X and Threads

## A new update focused on visual content

Bluesky continues to develop its platform and is now focusing on one of the most important elements of any social network — visual content. With its latest update, users can upload higher-quality photos, marking a key step toward competing with platforms like X and Threads.

Previously, Bluesky had limitations on image size and quality, which affected how posts looked. With the new update, those limits have been expanded, allowing images to be displayed at higher resolution.

## Larger images and a new display format

The updated app supports larger image uploads and displays photos at up to 4000 pixels. This brings Bluesky closer to the standards already set by major platforms.

In addition, a swipeable carousel has been introduced, allowing users to view multiple images without cropping or distortion. This is especially useful for content creators working with different aspect ratios.

## Closing the gap with competitors

This update clearly signals where Bluesky is heading. The platform is no longer just an experimental alternative but is evolving into a serious competitor.

X and Threads already offer advanced photo features and carousel formats. Bluesky is now working to close that gap and provide a similar user experience.

At the same time, the platform is responding to user feedback. Some users have already expressed a preference for more layout options, suggesting further updates could follow.

## Bigger picture: experience over features

This update is not just about technical improvements. It reflects a broader shift toward enhancing the overall user experience.

In social media, small changes can have a big impact. Image quality can determine whether a post stands out or gets ignored.
