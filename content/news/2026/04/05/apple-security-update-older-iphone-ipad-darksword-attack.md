# Apple releases security update for older devices

Apple has released an urgent security update for older iPhones and iPads at the beginning of April, responding to a serious threat known as DarkSword. As Metaadvisor.eu highlights, this is not just another technical update — it reflects a growing class of attacks that directly impact everyday users.

DarkSword is a sophisticated set of hacking tools capable of stealing sensitive data from devices — in some cases triggered simply by visiting a website. This makes the threat significantly more dangerous than traditional attacks that require user interaction or downloads.

## How the DarkSword attack works

DarkSword is a so-called “toolkit” — a collection of tools that exploit vulnerabilities in iOS versions between 18.4 and 18.7. The attack can be triggered simply by visiting a website that contains malicious code. Often, these are not obviously dangerous sites, but legitimate websites that have been compromised.

Once attackers gain access to a device, they can extract a wide range of data: messages, browsing history, location data, and even information stored in crypto wallets. The data is then automatically transmitted to servers controlled by the attackers, making this threat particularly serious for users who store digital assets or sensitive business information on their devices.

## A global threat that is expanding

Security researchers have already identified attacks in multiple countries, including China, Malaysia, Turkey, Saudi Arabia, and Ukraine. While such attacks are often initially targeted, the public release of these tools significantly changes the landscape.

As Metaadvisor notes, once advanced hacking tools become publicly available, the risk grows exponentially. It is no longer about isolated incidents, but about a potential large-scale threat affecting millions of users worldwide. This is why such updates are not just recommended — they are essential.

## Why users delay updates

Apple confirmed that users on the latest software are already protected, but the issue remains for those running older versions or delaying updates. Some users intentionally avoid updating due to design changes, including the new “liquid glass” interface, which has received mixed reactions.

This creates an interesting paradox: security and user experience can sometimes be in conflict. If interface changes cause frustration, some users prefer to stay on older versions — even at the cost of increased security risk.

## The bigger picture: security as a habit

This situation once again shows how closely digital security is tied to user behavior. Technology can provide protection, but only if users actively adopt it. Automatic updates, which many still disable, are becoming a critical line of defense.

In a world where a single click can compromise an entire device, security is no longer a question of “if” — but “when.”

## Our take (Metaadvisor)

* Security threats are becoming more sophisticated, but also more accessible to a wider audience
* The biggest risk today is not “hackers” — but unpatched devices
* Crypto assets on mobile devices are increasingly becoming a target
* UX (design) should not be a reason to avoid security updates
* The new Apple interface is perceived by many users as an unnecessary change — elements have been rearranged (what was at the top is now at the bottom), creating frustration rather than improvement
* This raises an important question: why change a functional layout that users are already familiar with? Are such changes driven by real needs or internal pressure for constant innovation?
* In practice, many users found the previous layout simpler and more intuitive — and such changes can lead to delays in critical security updates
