# Shopify Canvas Turns Sidekick Into an AI Designer for the Entire Online Store

**Shopify has introduced Canvas, a new AI tool that lets merchants build or redesign an entire online store by chatting with Sidekick. Unlike the traditional Shopify theme editor, Canvas shows multiple pages and templates inside one visual workspace, while Sidekick changes real theme files in real time and displays the result through the actual store render.**

The biggest change is not simply that users can talk to AI. Merchants no longer necessarily need to know which block, section or file to open. They can describe what they want, such as a different hero section, a new product page, a change to the style of the entire store or updates across several templates, and Sidekick attempts to identify and make the necessary code changes.

## Canvas shows the entire store in one workspace

One of the main differences from Shopify's existing editor is the way the store is presented. Canvas allows merchants to view multiple pages and templates inside one visual workspace, move across the entire store, zoom into individual areas and see how different pages work together as a whole.

Changes can still be made manually by clicking individual elements, but Shopify clearly wants a growing share of editing to begin through a conversation with Sidekick. Instead of arranging every block by hand, users can simply describe the result they want.

## This is not a static preview

Shopify specifically emphasizes that Canvas does not show a static mockup. Merchants see the store's actual code being rendered, which means they can test interactivity, animations, products, collections and layouts across different screen sizes.

Sidekick also uses screenshots of its own work. The AI therefore does not only check whether the code is technically correct, but also tries to see the same visual result the user sees.

That allows Sidekick to evaluate the result after making a change and improve it further when necessary.

## Sidekick now works directly on theme files

Sidekick is not a new Shopify AI tool. It has already been used for writing code, building apps, editing themes and handling other tasks. Shopify says Sidekick made more than 25 million theme edits during the first half of 2026 alone.

Canvas takes that existing tool to another level. Sidekick can now work directly on theme files, coordinate changes across different templates and check the result using a combination of code validation and screenshots.

Shopify has also adjusted the theme architecture to make it easier for Sidekick to understand the structure, logic and design of a store.

## Shopify says design was harder than code

One of the more interesting details from Shopify's own announcement is its admission that teaching AI to write code was not especially difficult. Teaching it to make good design decisions was much harder.

Technically correct code does not automatically mean a store will look good, have a clear hierarchy or remain visually consistent across multiple pages.

That is why Shopify uses theme rules, design patterns and large evaluation datasets so that Sidekick does not simply generate code, but also tries to preserve the style and logic of the entire store.

## Shopify says a custom store can be built in around 20 minutes

Shopify Director of Product Ben Sehl described the difference very directly. Twelve years ago, he said it took him roughly two weeks to build a rough version of a store even though he knew how to code. With Canvas and Sidekick, Shopify says a similar result can now be achieved in around 20 minutes.

That is Shopify's own comparison and should be treated as a marketing claim, but it clearly shows the ambition behind the product. Store building is meant to depend less on knowing Liquid, CSS, theme structures and traditional settings panels.

## Canvas is still in Early Access

Despite the ambition, Canvas is not yet a finished product. Shopify currently labels it as Early Access and it is not available to every store.

It works on desktop and is intended for stores on plans that support theme customization. Shopify also clearly states that Canvas does not yet replace the existing theme editor.

That is an important limitation because the tool still has several functional gaps that may matter for larger or more complex stores.

## Third-party themes and translations are not fully supported yet

One of the biggest current limitations is support for third-party themes. Stores with heavily customized designs or custom theme structures may not be able to use every Canvas feature.

There are also limitations around app blocks, app embeds, Markets, rollouts and translations. This is particularly important for multilingual stores because theme content cannot yet be fully localized and translated from within Canvas.

That shows Shopify Canvas is not yet ready to replace the existing workflow for every merchant.

## Shopify enters an increasingly crowded AI website builder market

Canvas arrives as Wix, Squarespace, Webflow and Framer are already aggressively adding AI to website creation, while tools such as Lovable and Replit are pushing development further toward a vibe-coding model.

Shopify still has one important advantage. It is not building a generic website builder, but an AI tool inside a highly specific ecommerce system that already understands products, collections, checkout, inventory, themes and apps.

Sidekick therefore does not only need to make a visually attractive website. It also needs to understand how a store actually works.

## AI usage could become an important hidden cost

Canvas also has another side that Shopify is not emphasizing much yet. An AI that continuously analyzes an entire store, changes code, renders results, reviews screenshots and iterates again can create significant compute costs.

For simple edits, those costs may remain limited. A merchant who spends hours chatting with Sidekick and requests dozens of design versions could generate far more AI usage than someone using the traditional theme editor.

Shopify has not yet published a detailed model for usage limits or extra charges tied to intensive Canvas use. Over time, it would therefore be reasonable to expect usage limits, advanced features tied to higher-priced plans or another method of controlling costs.

On the other hand, higher AI costs could still make sense for Shopify if Canvas increases the number of new stores, improves retention or drives higher GMV.

## Can Canvas reduce the need for developers?

For simple and moderately complex changes, very likely.

A merchant who previously had to hire a developer for a new hero section, a customized section or a template change may now be able to handle part of that work through Sidekick.

That does not mean developers become unnecessary. Complex integrations, performance, custom business logic, apps and deeper changes still require technical expertise.

The shift is more about developers becoming less necessary for every small visual adjustment.
