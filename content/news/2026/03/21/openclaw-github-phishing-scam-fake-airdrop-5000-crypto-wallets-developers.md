# GitHub phishing scam targets developers

GitHub, a platform widely considered a safe and professional environment by developers, has become the center of a new wave of crypto scams. In this campaign, attackers use fake token airdrops to trick users into connecting their crypto wallets — after which funds can be completely drained.

The campaign specifically targets developers involved with the OpenClaw project, an open-source AI framework that has recently gained significant attention. That very popularity makes it an ideal target for attackers looking to exploit trust within the developer community.

## How the scam works

Attackers create fake GitHub accounts and actively participate in repository discussions. They tag real developers in issue threads and inform them that they have been selected to receive a reward — a supposed airdrop worth around $5,000 in CLAW tokens.

The message appears credible because it comes from within a context the user already trusts. However, the link leads to a nearly identical clone of the official OpenClaw website. The key difference is an added step: the user is prompted to connect a crypto wallet.

Once the user clicks “connect wallet,” malicious actions can be triggered in the background. Transactions or approvals may be executed, allowing attackers to gain access to the user’s funds. From there, assets can be quickly transferred to attacker-controlled addresses.

## Why this attack is particularly dangerous

Unlike traditional phishing attempts via email or social media, this attack takes place inside a platform users inherently trust. GitHub is not just another social network — it is a working environment, which lowers users’ level of suspicion.

The attack also combines social engineering with technical execution. By targeting users who are already interacting with OpenClaw repositories, attackers create a strong sense of legitimacy. Messages that appear in a familiar context are far less likely to be questioned.

Additionally, phishing pages support widely used wallet solutions such as MetaMask, WalletConnect, and Trust Wallet, significantly increasing the number of potential victims.

## A growing trend: airdrops as a scam tool

This type of attack is not an isolated case. Increasingly, scammers are using airdrops as a primary lure. The idea of “free money” remains one of the strongest psychological triggers, especially in the crypto space.

Attackers combine this with technical mechanisms such as wallet connections and smart contract approvals. Once a user grants access, control over funds is often lost.

## Developer and project response

OpenClaw founder Peter Steinberger had already warned about the misuse of the project in crypto-related scams. The situation escalated to the point where he considered removing the entire project.

After scammers hijacked old OpenClaw accounts and used them to promote fake tokens, strict measures were introduced — including banning any mention of crypto on official project channels.

This response highlights how these scams can have real consequences, not only for users but also for developers and the projects themselves.

## How to protect yourself

⚠️ *MetaAdvisor does not offer token airdrops or request wallet connections. Always verify sources before interacting with any crypto-related links.*

The most important rule is simple: if you didn’t navigate to the official website yourself, do not connect your wallet. Any unexpected reward or airdrop should be treated as suspicious.

It is also recommended to use separate wallets for testing or interacting with new projects to minimize potential losses.
