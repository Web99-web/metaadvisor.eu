# Vercel hack uzdrmao Web3: API ključevi pod rizikom i panika među developerima

Sigurnosni incident u Vercelu, jednoj od ključnih cloud platformi za hosting modernih web aplikacija, izazvao je ozbiljnu zabrinutost među kripto developerima i Web3 projektima.

Radi se o platformi koja pokreće frontend velikog broja aplikacija — uključujući wallet sučelja, decentralizirane aplikacije (dApps) i dashboarde za upravljanje kripto sredstvima.

## Što se dogodilo

Napadač je uspio pristupiti internim Vercel sustavima putem kompromitiranog računa zaposlenika. Ulazna točka bio je AI alat treće strane — Context.ai — koji je bio povezan s Google Workspace računom zaposlenika.

Nakon kompromitacije tog računa, napadač je uspio proširiti pristup i doći do dijela internih sustava Vercela.

Posebno zabrinjava činjenica da su mogli biti izloženi API ključevi (Application Programming Interface — sučelje za povezivanje aplikacija), koji funkcioniraju kao digitalne lozinke između sustava.

{{< support1 >}}

## Zašto su API ključevi kritični

API ključevi omogućuju aplikacijama:

* pristup bazama podataka
* komunikaciju s blockchain servisima
* povezivanje s walletima i backend sustavima

Ako takvi ključevi završe u pogrešnim rukama:

* napadači mogu imitirati aplikaciju
* manipulirati podacima
* trošiti resurse ili izvršavati transakcije

U Web3 svijetu to može značiti i direktan financijski gubitak.

## Reakcija kompanije

Vercel je potvrdio da je kompromitiran ograničen broj korisničkih podataka te da su pogođeni korisnici odmah kontaktirani.

Preporuka je bila jasna:

👉 hitna rotacija API ključeva
👉 provjera svih sigurnosnih postavki
👉 analiza koda i pristupa

Tvrtka također tvrdi da su osjetljivi podaci dodatno zaštićeni i da nema dokaza o pristupu najkritičnijim informacijama.

{{< support1 >}}

## BreachForums i potencijalna prodaja podataka

Dodatnu zabrinutost izazvala je objava na hakerskom forumu BreachForums, gdje je navodno ponuđena prodaja Vercel podataka za 2 milijuna dolara.

Prema tim tvrdnjama, paket uključuje:

* API ključeve
* izvorni kod
* pristupne podatke zaposlenika
* baze podataka

Iako Vercel nije potvrdio sve ove navode, priznao je da je napadač bio visoko sofisticiran.

## Širi problem: centralizirana infrastruktura Web3-a

Ovaj incident otkriva jednu od najvećih slabosti Web3 ekosustava.

Iako se govori o decentralizaciji, velik dio infrastrukture i dalje ovisi o centraliziranim servisima poput Vercela.

To znači:

* jedna sigurnosna rupa može utjecati na tisuće projekata
* napad se može proširiti kroz tzv. supply chain
* rizik nije izoliran na jednu aplikaciju

## Što slijedi

Vercel trenutno surađuje sa sigurnosnim stručnjacima i policijom kako bi utvrdio puni opseg napada.

Za developere i projekte, ovo je podsjetnik:

sigurnost ne završava na blockchainu — ona počinje na infrastrukturi.

## Zaključak

Incident u Vercelu pokazuje koliko je krhka ravnoteža između decentralizacije i stvarne tehničke infrastrukture.

Jedan kompromitirani račun može pokrenuti lančanu reakciju koja pogađa cijeli ekosustav.
