# Anthropic Mythos als Claude Fable 5 geht an die Öffentlichkeit: Lässt sich gefährliche AI-Fähigkeit wirklich begrenzen?

Anthropic hat laut Berichten von Reuters und Axios **Claude Fable 5**, das erste breit verfügbare Modell aus der sogenannten **Mythos**-Klasse, öffentlich vorgestellt. Hinter diesem Namen steht nicht nur ein weiterer „stärkerer Chatbot“, sondern eine deutlich sensiblere Geschichte: Es geht um AI-Modelle, die in früheren Tests sehr fortgeschrittene Fähigkeiten im Bereich der Cybersicherheit gezeigt haben, darunter Codeanalyse, das Auffinden von Schwachstellen und potenziell auch das Verständnis dafür, wie Sicherheitslücken ausgenutzt werden könnten.

Deshalb ist diese Veröffentlichung nicht nur für Nutzer wichtig, die ein schnelleres und intelligenteres AI-Tool zum Schreiben, Programmieren oder Analysieren von Daten wollen. Sie wirft eine größere Frage auf: Was passiert, wenn Modelle, die bei der Verteidigung digitaler Systeme helfen können, stark genug werden, um in den falschen Händen auch Angreifern zu helfen?

## Was ist Anthropic Mythos eigentlich?

Mythos ist ein Name, der mit einer fortgeschrittenen Klasse von AI-Modellen von Anthropic verbunden wird, die besonders wegen ihrer Cybersecurity-Fähigkeiten interessant sind. In einer früheren Preview-Phase war das Modell nur einer begrenzten Zahl von Organisationen, Sicherheitspartnern und staatlichen Institutionen über kontrollierte Zugangsprogramme verfügbar. Anthropic erklärte damals, Mythos könne beim Auffinden von Softwareschwachstellen helfen — ein großer Vorteil für die Verteidigung von Systemen, aber gleichzeitig ein sehr sensibles Thema.

Einfach gesagt kann ein solches Modell wie ein sehr fähiger Sicherheitsanalyst wirken. Es kann Code prüfen, verdächtige Teile eines Systems erkennen, Informationen verbinden und Hinweise geben, wo eine Schwachstelle liegen könnte. Für Unternehmen, Regierungen und Sicherheitsteams, die Lücken schließen wollen, bevor sie ausgenutzt werden, ist das ein enormer Vorteil.

{{< support1 >}}

Doch genau diese Fähigkeit hat auch eine andere Seite. Wenn ein Modell eine Schwachstelle zur Verteidigung finden kann, stellt sich die Frage, ob jemand mit schlechten Absichten dasselbe Modell auch für einen Angriff nutzen könnte. Genau deshalb hat Mythos so viel Aufmerksamkeit erzeugt. Das Problem ist nicht nur, wie intelligent das Modell ist, sondern was es in einem sehr sensiblen Bereich leisten kann.

## Claude Fable 5: eine öffentliche Version mit Bremsen

Laut den Berichten von Reuters und Axios veröffentlicht Anthropic nun Claude Fable 5 als Modell der Mythos-Klasse, jedoch mit Schutzmechanismen. Anders gesagt: Die Öffentlichkeit bekommt nicht den vollständigen „Cyber-Mythos“ ohne Einschränkungen, sondern eine Version, die stark genug für allgemeine Nutzung sein soll, aber in den riskantesten Bereichen begrenzt wird.

Das bedeutet, dass Claude Fable 5 sehr leistungsfähig beim Programmieren, Analysieren, Schreiben, bei Geschäftsaufgaben und komplexem Denken sein dürfte, aber Nutzern nicht frei bei hochriskanten Cyber-Aufgaben helfen soll. Wenn ein Nutzer Hilfe bei gefährlichen Sicherheitsszenarien sucht, soll das System nach den Beschreibungen die Antwort auf ein sichereres Modell oder eine sicherere Antwortstufe umleiten oder einschränken.

Auf dem Papier klingt das wie ein logischer Kompromiss. Anthropic will zeigen, dass es der Öffentlichkeit die fortschrittlichste Modellklasse anbieten kann, ohne die Tür für Missbrauch vollständig zu öffnen. Die große Frage bleibt jedoch: Kann eine gefährliche Fähigkeit wirklich nur durch Regeln, Filter und Guardrails „ausgeschaltet“ werden?

## Warum ist Cybersecurity so sensibel?

Cybersecurity, also Cybersicherheit, ist ein besonders sensibles Gebiet, weil die Grenze zwischen Verteidigung und Angriff oft von der Absicht des Nutzers abhängt. Dieselbe Anfrage kann völlig legitim sein, wenn sie von einem Sicherheitsexperten gestellt wird, der das eigene System testet. Sie kann aber gefährlich sein, wenn ein Angreifer eine Schwachstelle in einem fremden System sucht.

Zum Beispiel kann die Analyse von verwundbarem Code nützlich sein, wenn ein Unternehmen seine Software reparieren will. Wenn dieselbe Analyse jedoch dazu genutzt wird, einen Weg in ein System zu finden, bevor es gepatcht ist, wird dieselbe Fähigkeit zur Bedrohung. Deshalb sind Modelle wie Mythos deutlich sensibler als gewöhnliche AI-Tools zum Schreiben von Texten oder Zusammenfassen von Dokumenten.

Ein besonderes Problem ist die Geschwindigkeit. Ein AI-Modell kann riesige Mengen an Code prüfen, Informationen verbinden und Hypothesen viel schneller testen als ein durchschnittlicher Mensch. Das kann der Verteidigung helfen, aber auch Angriffe beschleunigen. Wenn die stärksten Werkzeuge nur großen Unternehmen, Regierungen und reichen Organisationen zur Verfügung stehen, entsteht außerdem eine Frage der Ungleichheit: Wer hat Zugang zur besten Verteidigung, und wer bleibt ungeschützt?

## Anthropic versucht, Sicherheit als Teil des Produkts zu verkaufen

Anthropic versucht seit Längerem, sich als AI-Unternehmen zu positionieren, das Sicherheit in den Vordergrund stellt. Das ist Teil seines öffentlichen Images: starke Modelle, aber mit Fokus auf Kontrolle, Risikobewertung und verantwortliche Veröffentlichung. Claude Fable 5 ist deshalb nicht nur ein technisches Produkt, sondern auch ein Reputations-Test.

Wenn das Modell wirklich nützlich ist und gleichzeitig nicht leicht missbraucht werden kann, könnte Anthropic zeigen, dass Frontier-AI-Modelle der Öffentlichkeit zugänglich gemacht werden können, ohne die Kontrolle vollständig zu verlieren. Wenn sich jedoch zeigt, dass Guardrails umgangen werden können oder Nutzer trotzdem gefährliche Cyber-Anleitungen erhalten, wird die gesamte Geschichte deutlich ernster.

## Was bedeutet das für normale Nutzer?

Für normale Nutzer wird Claude Fable 5 wahrscheinlich wie ein weiteres fortschrittlicheres AI-Tool wirken: besser beim Coden, besser bei komplexen Aufgaben, besser in der Analyse und vielleicht teurer als frühere Versionen. Doch hinter der Benutzeroberfläche verbirgt sich eine deutlich ernstere Debatte.

Wenn solche Modelle in Programmierung, Geschäftssystemen, Finanzen, Infrastruktur und Sicherheit eingesetzt werden, werden sie langsam Teil der digitalen Infrastruktur. Sie sind dann nicht mehr nur Assistenten zum Schreiben einer E-Mail oder eines Artikels. Sie werden Werkzeuge, die an technischen Entscheidungen, Risikoanalysen und der Verteidigung von Systemen mitwirken können.

Das bedeutet, dass sich die Frage der AI-Sicherheit nicht mehr nur darauf bezieht, ob ein Modell eine falsche Antwort schreibt. Die Frage wird: Kann ein Modell beim Auffinden realer Schwachstellen helfen? Kann es diese Schwachstellen so erklären, dass sie einem Angreifer nützen? Und kann eine solche Fähigkeit wirklich präzise auf „gute“ Nutzer beschränkt werden?

## Die größte Frage: Können Guardrails ausreichen?

Guardrails sind Schutzmechanismen, die verhindern sollen, dass ein Modell auf gefährliche oder verbotene Anfragen antwortet. Das Problem ist, dass die Geschichte von AI-Modellen zeigt, dass Nutzer ständig Wege suchen, Einschränkungen zu umgehen. Manchmal geschieht das durch anders formulierte Anfragen, manchmal durch Kontext und manchmal durch eine Reihe kleiner Schritte, die einzeln nicht gefährlich wirken, zusammen aber zu einem riskanten Ergebnis führen.

Bei gewöhnlichen Themen kann das unangenehm sein. Im Bereich Cybersecurity kann es ein ernsthaftes Problem werden. Wenn ein Modell keine direkte Angriffsanleitung geben darf, dem Nutzer aber über mehrere Schritte trotzdem hilft, dasselbe Ziel zu erreichen, hat die Sicherheitsbarriere das Problem nicht wirklich gelöst.

Deshalb werden rund um Fable 5 und die Mythos-Klasse wahrscheinlich zwei Debatten parallel laufen. Eine wird kommerziell sein: Wie gut ist das Modell, wie viel kostet es und wie sehr kann es Unternehmen helfen? Die andere wird sicherheitsbezogen sein: Wie real sind die Einschränkungen, und können sie dem Druck von Nutzern standhalten, die sie absichtlich umgehen wollen?

## Unsere Einschätzung (Metaadvisor)

- Claude Fable 5 von Anthropic ist nicht einfach nur ein weiteres neues AI-Modell. Es ist ein Test dafür, ob eine sehr fortgeschrittene AI-Fähigkeit öffentlich angeboten werden kann, während die riskantesten Funktionen kontrolliert bleiben.

- Die Mythos-Klasse ist besonders sensibel, weil sie mit Cybersecurity-Fähigkeiten verbunden wird. Das ist ein Bereich, in dem dasselbe Werkzeug sowohl der Verteidigung als auch dem Angriff dienen kann.

- Die wichtigste Frage ist nicht nur, wie intelligent das Modell ist, sondern wer Zugang zu den vollen Fähigkeiten hat und wie zuverlässig gefährliche Anfragen wirklich begrenzt werden können.

- Wenn Guardrails gut funktionieren, könnte dies ein wichtiger Schritt hin zu einer sichereren öffentlichen Nutzung von Frontier-AI-Modellen sein. Wenn sie nicht gut genug funktionieren, kann sich das Risiko schnell vom Labor in die reale Welt verlagern.

- Für normale Nutzer ist dies ein weiteres Zeichen dafür, dass AI nicht mehr nur ein Werkzeug zum Schreiben und Übersetzen ist. Wir treten in eine Phase ein, in der AI-Modelle immer stärker die Sicherheit von Software, Infrastruktur und digitaler Wirtschaft beeinflussen.
