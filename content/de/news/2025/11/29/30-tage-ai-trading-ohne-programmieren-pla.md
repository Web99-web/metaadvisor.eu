# 🔍 Plattform-Erklärungen: Hyperliquid, Kryll und MEXC

## ✅ **1. Hyperliquid AI Agents (DeFi L2 ohne KYC)**
Hyperliquid ist eine **dezentrale Börse (DEX)** auf einer eigenen Layer-2.  
Der besondere Vorteil sind **AI Agents**, die vollautomatisch traden.

**So startest du mit Hyperliquid AI Agents:**  
1. MetaMask installieren  
2. https://app.hyperliquid.xyz öffnen  
3. USDT/USDC via Bridge einzahlen  
4. Menü → **AI Agents**  
5. Bot auswählen → *Activate*

Vorteile:
- kein KYC  
- extrem schnelle L2  
- AI-Bots laufen 24/7  

Nachteile:
- Wallet-Verständnis nötig  

---

## ✅ **2. Kryll.io — Marketplace für AI-Strategien**
Kryll ist eine No-Code-Trading-Plattform mit fertigen Strategien.

Auf Kryll:
- AI- oder quantbasierte Strategien auswählen  
- mit MEXC/KuCoin/Binance via API verbinden  
- Bot mit einem Betrag starten  

**So startest du auf Kryll:**  
1. https://kryll.io öffnen  
2. Account erstellen  
3. MEXC-API verbinden  
4. Strategie aus dem Marketplace auswählen  
5. Start klicken

Vorteile:
- sehr einfach  
- großer Strategie-Marktplatz  

Nachteile:
- Strategien müssen getestet werden  

---

## ✅ **3. MEXC — beste CEX für Anfänger (kein KYC für Spot)**
MEXC ist ideal für AI-Bots:

- keine Verifikation für Spot  
- riesige Auswahl an Coins  
- niedrige Gebühren  
- schnelle Ausführung  

**Start auf MEXC:**  
1. Registrieren (E-Mail)  
2. USDT/BTC einzahlen  
3. Spot handeln ohne KYC  
4. Oder Via API mit Kryll verbinden
